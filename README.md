## 📌 Technical Overview
**HIITFit** is a personal interval training companion designed to guide users through structured exercise routines. It demonstrates clean state management in SwiftUI, video playback for exercise technique, rating evaluations, and persistent session recording via a custom `HistoryStore`.

### 💼 Technical Highlights
- **State-Driven Timer Engine**: Custom countdown interval timers with visual circular progress indicators.
- **Persistent Workout History**: Local history storage tracking completed exercise sessions across calendar dates.
- **Embedded Exercise Video Player**: Native video instruction for proper form and posture.
- **Rating & Assessment System**: Interactive 5-star rating system capturing workout difficulty.

## 🚀 Setup & Run
1. Clone the repository:
   ```bash
   git clone https://github.com/snaimio/HIITFit.git
   cd HIITFit
   open HIITFit.xcodeproj
   ```
2. Build and run via Xcode (`⌘ + R`).
